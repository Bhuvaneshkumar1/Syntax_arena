Core Game Mechanics & Scoring Engine

Base Scoring

Points scale by cognitive complexity: 100 pts (Beginner), 200 pts (Intermediate), and 300 pts (Expert).

Streak Multipliers

Consecutive correct deductions add +0.25x up to a maximum 3.0x multiplier (8-streak). Incorrect answers reset the streak to 1.0x.

Pedagogical Hints

Hints provide targeted architectural clues with a fixed deduction (-25 pts Beginner, -60 pts Intermediate, -100 pts Expert).

Second Chance Retries

If a hint was activated prior to answering, an incorrect submission grants one Second Chance retry awarding 50% base points while freezing streak.

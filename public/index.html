Gameplay Rules

How to Play SyntaxArena

A quick four-step overview of scoring, multipliers, hints, and retries.

Verified Rules
STEP 1

Choose Language

Pick between Python 3, C, C++, or Java. You can switch tracks anytime without losing progress in other tracks.

STEP 2

Select Difficulty

Start with Beginner foundations, or test your skills on Intermediate state logic and Expert edge cases.

STEP 3

Solve Challenges

Answer output predictions, pinpoint bugs, and complete missing code. Keyboard shortcuts (1–4, A–D) supported.

STEP 4

Review & Progress

Read detailed technical explanations after each question to build deep conceptual understanding and earn XP.

Core Game Mechanics & Scoring Engine

Base Scoring

Points scale by cognitive complexity: 100 pts (Beginner), 200 pts (Intermediate), and 300 pts (Expert).

Streak Multipliers

Consecutive correct deductions add +0.25x up to a maximum 3.0x multiplier (8-streak). Incorrect answers reset the streak to 1.0x.

Pedagogical Hints

Hints provide targeted architectural clues with a fixed deduction (-25 pts Beginner, -60 pts Intermediate, -100 pts Expert).

Second Chance Retries

If a hint was activated prior to answering, an incorrect submission grants one Second Chance retry awarding 50% base points while freezing streak.

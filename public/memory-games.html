📖 Memory Lab Operations Manual

🔌 Stack Master: Virtual Cable Routing

In low-level programming (C/C++), a pointer does not store data directly; it holds the 64-bit hexadecimal memory address (e.g. 0x55a100) of an allocation on the heap or stack.

How to Play: 1. Select Source: Click the cyan circular socket on the right edge of any stack pointer variable (e.g., ptr). The socket will pulse yellow.
2. Plug Target: Click the purple target socket on the left of the allocated heap chunk (e.g., 0x55a100 malloc(sizeof(int))).
3. Auto-Validation: The system automatically verifies your route immediately upon completing all required connections! Correct routes glow emerald green and advance you forward.
4. Disconnecting: Click any active cable wire to instantly unplug it.

🧹 Heap Hunter: Mark-and-Sweep Garbage Collector

Dynamic heap memory must be freed when no longer in scope. If a pointer handle is overwritten without calling free(), the memory block becomes orphaned, wasting RAM.

How to Play: 1. Trace Roots: Inspect active stack root pointers in the left column. Follow their targets.
2. Spot Orphans: If a heap chunk has no live pointer referencing it, it is a memory leak.
3. Reclaim: Click "Free Block" on the orphaned block to deallocate it and lower the heap capacity gauge.
4. ⚠️ Danger — Use-After-Free: Never free an active block that is still referenced by a stack pointer! Doing so triggers a fatal Use-After-Free alert and resets your streak.

⚡ Segfault Defuser: Rapid Memory Hazard Triage

You have 12 seconds per rapid-fire code snippet to diagnose pointer memory safety before CPU hardware interrupts trigger a segmentation fault.

🟢 SAFE ACCESS:
Valid pointer assigned to real stack/heap memory before dereference.
🟡 NULL POINTER:
Dereferencing explicit address 0x0 / NULL (SIGSEGV).
🔴 DANGLING / UAF:
Dereferencing memory after free() or out of scope stack frame.
🟣 BUFFER OVERRUN:
Accessing indexes past allocation boundary (e.g. arr[10] on length 5).
